# PYTHON-PROJECT-2
UK Railway Travel Analysis is a Python-based data analysis project using mock National Rail ticket data from January to April 2024. The project explores railway travel patterns, ticket sales, pricing, revenue, routes, and service performance.
## Project Overview
Railway Riders Travel Analysis is a Python-based data analysis project that explores UK railway travel data. The project analyzes ticket purchases, passenger travel patterns, popular routes, peak travel hours, service reliability, delays, cancellations, and revenue performance.
## Objectives

- Analyze railway ticket purchasing trends
- Identify the most popular routes
- Find peak travel hours
- Analyze on-time, delayed, and cancelled journeys
- Identify the major causes of delays and cancellations
- Analyze monthly revenue and revenue changes
- Understand the financial impact of cancellations
- Identify key operational insights
